# C Projects

A collection of my C programming projects, experiments, and implementations.

## Projects

### recreating-printf
A simple recreation of the C `printf` function using variadic functions and write syscall for ints and chars

More information:
- [References](recreating-printf/REFERENCES.md)

### recreating-scanf
A recreation of the C `scanf` function also using variadic functions, this time I had to (kind of) recreate strcpy for string inputs

### contacts-list
A CLI contact manager built as practice for pointers, structs, dynamic arrays, and file I/O, supports adding and listing contacts, with state (contact count) saved between runs via two save files
> Not happy with the current state, it's grown a bit messy, and remove-contact functionality is still TODO
